This repository is an earlier build in the game lineage now published as **Legocraft**, also previously described as **Brick XR Builder**, **Brick XR**, **The Lego Game**, and **The Lego Game 2**.

It is preserved as development history and is **not a separate game**.

The current lineage is a browser based 3D brick building sandbox with placement, editing, saved builds, export and WebXR support. Use `Joenasriani/legocraft` as the canonical source repository.

This independent project is not affiliated with or endorsed by the LEGO Group.

## Historical build capabilities

- snap to grid brick placement
- build, move, delete and rotate modes
- undo and redo
- local saved scene state
- 3D model export
- desktop and touch controls

Existing branches and historical files are retained as development backups.
